# Edificio MORAR — Portal de Transparencia y Rendición de Cuentas

Dashboard interactivo para visualizar los ingresos, egresos y la cronología histórica de eventos del Edificio MORAR (Surquillo, Lima) correspondiente al período 2024–2026.

## Características
- **Vista Mensual:** Desglose interactivo mes por mes (Abril a Setiembre 2025) y consolidado semestral.
- **Gráficos Dinámicos:** Comparativa de Ingresos vs Egresos y estructura porcentual de gastos con Chart.js.
- **Línea de Tiempo:** Historial de 16 actas de asamblea, elecciones de Junta Directiva y resoluciones con empresas administradoras.
- **Buscador en tiempo real:** Filtro instantáneo de partidas y conceptos de mantenimiento.
